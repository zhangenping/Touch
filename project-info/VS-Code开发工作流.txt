VS Code 完整开发工作流 — F:\Touch
==================================

一、打开项目
------------
方法 A（推荐）：
  1. 打开 VS Code
  2. 菜单：文件 → 打开文件夹
  3. 选择 F:\Touch → 确定

方法 B：
  资源管理器中进入 F:\Touch，右键 → 通过 Code 打开

方法 C（命令行）：
  code F:\Touch


二、首次准备（只需一次）
------------------------
1. 安装 Node.js LTS：https://nodejs.org/
2. VS Code 终端：Ctrl + ` 打开
3. 执行：
   npm install
4. 若弹出扩展推荐，可安装：
   - ESLint
   - Prettier


三、日常开发循环
----------------
┌─────────────────────────────────────────┐
│ 1. 启动开发服务器                          │
│    终端：npm run dev                       │
│    或：Ctrl+Shift+B → dev: 开发服务器       │
│    浏览器：http://localhost:5173           │
├─────────────────────────────────────────┤
│ 2. 改内容（不用动 React 代码）              │
│    content/site.json — 文案、项目、链接    │
│    public/assets/images/ — 图片            │
│    public/assets/videos/ — 视频 MP4        │
├─────────────────────────────────────────┤
│ 3. 保存 → 浏览器自动刷新查看效果            │
├─────────────────────────────────────────┤
│ 4. 改页面样式/组件（可选）                  │
│    src/pages/          — 各页面            │
│    src/components/     — 视频、导航等       │
│    src/styles/         — 全局 CSS 变量      │
└─────────────────────────────────────────┘


四、VS Code 快捷任务（已配置 .vscode/tasks.json）
------------------------------------------------
Ctrl + Shift + P → 输入 “Tasks: Run Task”：

  dev: 开发服务器          — 日常开发
  dev: 局域网手机预览      — 手机同 WiFi 访问
  build: 生产构建          — 生成 dist/
  preview: 预览构建结果    — 本地看上线效果 http://localhost:4173


五、手机预览（同一 WiFi）
-------------------------
任务：dev: 局域网手机预览
或终端：npm run dev -- --host

用手机浏览器打开终端里 Network 地址，例如：
  http://192.168.1.10:5173/


六、上线前检查
--------------
1. npm run build        （无报错）
2. npm run preview      （本地检查 dist）
3. 部署见：部署与访问步骤.txt 或 scripts/deploy.ps1


七、Git 版本管理（可选）
------------------------
终端：
  git status
  git add content/site.json
  git commit -m "update resume content"

VS Code 左侧「源代码管理」图标可图形化提交。


八、目录速查（改哪里）
----------------------
  content/site.json           所有文字、项目、社交链接
  public/assets/images/       头像、生活照
  public/assets/videos/       演示视频
  src/pages/                  页面布局
  src/components/VideoPlayer/ 视频播放器
  project-info/               说明文档（本文件所在目录）
