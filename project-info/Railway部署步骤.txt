Railway 公网部署步骤（后续使用）
================================

前置：本机 Docker 已能正常访问 http://localhost:3001 再部署到 Railway。

一、准备 GitHub
---------------
  代码已在：https://github.com/zhangenping/Touch
  本地有新改动时：
    git add .
    git commit -m "说明"
    git push


二、注册 Railway
----------------
  1. 打开 https://railway.app
  2. 用 GitHub 登录
  3. 授权访问仓库


三、创建项目
------------
  1. Dashboard → New Project
  2. 选 Deploy from GitHub repo
  3. 选择仓库 zhangenping / Touch
  4. 分支选 master（或 main）


四、添加 PostgreSQL 数据库
--------------------------
  1. 在项目画布 Empty → 点 + Add Service
  2. 选 Database → PostgreSQL
  3. 等数据库部署完成
  4. 点 Postgres 服务 → Variables 或 Connect
  5. 复制 DATABASE_URL（形如 postgresql://postgres:xxx@...）


五、配置 Web 服务环境变量
-------------------------
  点 Touch（Web）服务 → Variables → Add：

    DATABASE_URL     = <粘贴 Postgres 的 URL>
    JWT_SECRET       = <至少32位随机字符串>
    NODE_ENV         = production
    PORT             = 3001

  Railway 会自动注入 PORT，也可不手写 PORT。


六、配置构建与启动命令
----------------------
  Web 服务 → Settings：

  Build Command（构建）：
    npm install && npm run db:generate && npm run build

  Start Command（启动）：
    npm run db:deploy && npm start

  Root Directory：留空（项目根目录）

  Watch Paths：默认即可


七、生成公网域名
----------------
  Web 服务 → Settings → Networking → Generate Domain

  得到类似：
    touch-production-xxxx.up.railway.app

  手机/任意电脑浏览器打开该地址即可注册、登录。


八、验证
--------
  1. 打开 https://你的域名.up.railway.app/register
  2. 注册账号
  3. 登录后浏览 HOME / RESUME 等

  若失败：Deployments → 查看最新日志


九、Railway 与 Docker 服务器对比
--------------------------------
  |          | Docker 云服务器      | Railway              |
  |----------|----------------------|----------------------|
  | 运维     | 自己管 SSH、防火墙   | 平台托管             |
  | 国内速度 | 选国内云较快         | 服务器多在海外       |
  | 费用     | 轻量机约50元/月起    | 有免费额度，超出计费 |
  | 适用     | 长期、国内用户多     | 快速上线、海外访问   |


十、更新网站
------------
  推送到 GitHub 后 Railway 通常自动重新部署。
  数据库迁移若新增表，Start Command 已含 db:deploy 会自动执行。
