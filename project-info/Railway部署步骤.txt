Railway 部署步骤（用项目 Dockerfile，等同本地 Docker 网站容器）
================================================================

重要说明
--------
  ❌ 不能把 docker-compose.prod.yml 原样上传到 Railway 跑两个容器。
  ✅ 可以：GitHub 代码 + 项目根目录 Dockerfile（与本地 touch-app 镜像相同逻辑）。
  ✅ 数据库：在 Railway 里单独添加 PostgreSQL 插件（代替 compose 里的 db 容器）。

架构对照
--------
  本地 Docker：
    touch-db-1 (Postgres)  +  touch-app-1 (Dockerfile 构建)

  Railway：
    PostgreSQL 插件服务      +  Touch 服务（用 Dockerfile 构建）


一、前提
--------
  代码已推送到：https://github.com/zhangenping/Touch
  本地 Docker 已能打开 http://localhost:3001（可选，用于验证）


二、创建 Railway 项目
--------------------
  1. 登录 https://railway.app
  2. New Project → Deploy from GitHub repo
  3. 选择 zhangenping / Touch，分支 master


三、添加 PostgreSQL（代替 Docker 里的 db）
------------------------------------------
  1. 项目画布 → + New → Database → PostgreSQL
  2. 等 Postgres 服务变为 Active
  3. 打开 Postgres → Variables 或 Connect → 复制 DATABASE_URL


四、配置 Web 服务（Touch）— 用 Dockerfile
-----------------------------------------
  1. 点开从 GitHub 部署出来的 Touch 服务
  2. Settings → Build：
       Builder：Dockerfile
       Dockerfile Path：Dockerfile（默认根目录）
     （不要填 npm build 那套，除非不用 Docker）

  3. Settings → Deploy：
       清空自定义 Start Command（用 Dockerfile 里 CMD 即可）
       或保留为空，让镜像启动时自动：
         prisma migrate deploy && node server/dist/index.js

  4. Variables → 添加/引用：

       DATABASE_URL = ${{Postgres.DATABASE_URL}}
       （或手动粘贴 Postgres 的 DATABASE_URL）

       JWT_SECRET   = <至少32位随机字符串，自行生成>

       NODE_ENV     = production

     说明：PORT 由 Railway 自动注入，程序会读取，无需写死 3001。

  5. Networking → Generate Domain → 得到公网地址


五、首次部署与验证
------------------
  Deployments 里等待 Build + Deploy 成功（约 3～10 分钟）。

  浏览器打开：
    https://你的域名.up.railway.app/register

  注册 → 登录 → 浏览页面。


六、与本地 Docker 的差异
------------------------
  | 项目           | 本地 docker-compose.prod | Railway        |
  |----------------|--------------------------|----------------|
  | 网站镜像       | Dockerfile 构建          | 同一 Dockerfile |
  | 数据库         | db 容器                  | Postgres 插件   |
  | 连接串         | touch:touch_secret@db    | Railway 提供的 URL |
  | 访问地址       | localhost:3001           | *.up.railway.app |

  环境变量 DATABASE_URL 必须指向 Railway Postgres，不能用 localhost。


七、常见问题
------------
  Q：构建失败拉不到 node 镜像？
  A：Railway 在海外，一般用官方 node:22-alpine 即可；
     本地 Dockerfile 的 NODE_IMAGE 镜像加速参数在 Railway 可不设。

  Q：数据库连接失败？
  A：确认 Touch 服务 Variables 里 DATABASE_URL 已关联 Postgres。

  Q：打开域名 502？
  A：看 Deploy Logs；确认 migrate 成功、JWT_SECRET 已设置。

  Q：推送 GitHub 后如何更新？
  A：Railway 自动重新构建 Dockerfile 并部署。


八、费用提示
------------
  Railway 按用量计费，有试用额度；Postgres + Web 两个服务都会占额度。
